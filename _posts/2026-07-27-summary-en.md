Pebble v2 is used when bootstrapping a new database; existing Pebble v1 databases must be manually upgraded via &\#x27;geth db pebble-upgrade&\#x27;. The GOGC change adjusts the garbage collector trigger threshold, trading higher memory usage for lower CPU overhead.

github · rjl493456442 · Jul 27, 16:17

**Background**: GOGC is a Go runtime environment variable that controls the garbage collector&\#x27;s target percentage: a higher value means the GC runs less frequently, reducing CPU time but increasing peak memory. Pebble is a key-value store written in Go, initially used in go-ethereum as an alternative to LevelDB. The Amsterdam hardfork is a planned Ethereum upgrade that includes multiple EIPs to improve gas accounting, increase contract size, and introduce block-level access lists, building on changes from earlier forks.
