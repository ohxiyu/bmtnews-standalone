BMTNews 通过公开仓库提供可核查的联系路径，不要求读者创建额外的站内账号。普通错误、
页面问题、API 兼容性问题、功能建议和公开信息源建议，可以在
[GitHub Issues](https://github.com/ohxiyu/bmtnews-standalone/issues/new/choose)
中提交。请提供受影响的 BMTNews URL、发生时间、预期结果和可公开验证的证据；不要在
公开 Issue 中放入 API Key、登录凭据、私人身份文件、未公开漏洞细节或其他敏感资料。

内容权利、删除或更正请求应使用专门的
[rights request](https://github.com/ohxiyu/bmtnews-standalone/issues/new?template=rights_request.md)
模板，并标明具体页面、条目和原始材料。公开来源新增或调整建议可以使用普通 Issue，
说明来源地址、内容类型、建议分类和调整原因。BMTNews 会保留编辑判断，不保证收录每个
来源，也不会通过公开表单接收付费排名、秘密投放或绕过来源验证的请求。

For ordinary bugs, corrections, API interoperability reports, feature
requests, and public source suggestions, open a
[GitHub issue](https://github.com/ohxiyu/bmtnews-standalone/issues/new/choose).
Include the affected URL, date, expected behavior, and evidence that can be
shared publicly. Rights and removal concerns should use the dedicated rights
request template linked above.

Security vulnerabilities must not be filed as public issues. Use GitHub's
private [security advisory form](https://github.com/ohxiyu/bmtnews-standalone/security/advisories/new)
so only repository maintainers can read the report. Include reproduction steps,
the affected version or endpoint, and a minimal proof of concept. These public
and private repository channels are the currently supported contact methods;
BMTNews does not publish a telephone number or physical office address.
