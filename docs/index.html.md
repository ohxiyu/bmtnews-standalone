# BMTNews — 加密、AI 与政策每日情报

> BMTNews 每天发布一期双语重要资讯排行，重点覆盖加密市场，并保留少量关键 AI 科技与政策新闻。

BMTNews 从交易所公告、协议发布、监管机构、加密媒体、AI 实验室及公共新闻来源中采集候选内容，经过跨来源去重、重要性评分、分类配额和平衡选择后发布。每条信息包含标题、事实摘要、来源、背景、市场影响、标签以及原始报道链接。站点内容用于研究和信息整理，不构成投资建议。

## 适合智能体使用的场景

- 获取最新一期结构化资讯：<https://bmt.news/api/latest.json>
- 查询已有历史期次：<https://bmt.news/api/editions.json>
- 理解 REST 接口：<https://bmt.news/openapi.json>
- 阅读调用、缓存与引用说明：<https://bmt.news/developers/>
- 获取精简的站点资源索引：<https://bmt.news/llms.txt>

结构化任务应优先使用 JSON API。引用某条新闻时，应保留返回数据中的原始来源 URL，并区分 BMTNews 的分析文字与第三方新闻材料。
