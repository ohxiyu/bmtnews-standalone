    比特币侧链 Liquid 遭攻击，约3.2亿美元被提取

    2026年9月6日，比特币侧链 Liquid Network 遭遇安全漏洞攻击，约4000枚BTC（约3.2亿美元）被提取，网络运营方随即暂停了所有交易。攻击者自称是道德安全研究员，声称他们是“好人”。 Liquid 是比特币上用于机构结算和数字资产发行的主流二层侧链，如此规模的漏洞会削弱市场对基于比特币的托管和侧链安全的信心。这是比特币侧链生态中最严重的安全事件之一，可能引发对桥接和锚定资产风险的重新审视。 Liquid 是一个由 Blockstream 和一组功能节点运营的联盟侧链，这意味着被盗的比特币由受信方通过多重签名保管，而非简单的智能合约。黑客声称自己是“好人”，暗示此次利用可能被构造成白帽救援行动；事件调查期间，网络已暂停区块生产。

    Liquid Network 遭黑客攻击：约3.2亿美元比特币被取出

    由 Blockstream 开发的比特币侧链 Liquid Network 遭到攻击，约 3.2 亿美元（约 4,000/4,200 枚比特币）通过 SideSwap 从联邦钱包中被取出。此次事件被追溯到 Blockstream Elements 软件中的一个漏洞，网络目前已暂停。 这是比特币侧链上最大规模的安全事件之一，引发了对联邦侧链安全模型以及桥接至二层解决方案的资金安全的严重质疑。事件影响 Liquid 用户、交易所，以及使用 Liquid 进行代币化资产和更快速交易结算的机构。 攻击者利用 Elements 软件中的漏洞，通过 SideSwap 协议从 Liquid 联邦钱包中取出了比特币。Blockstream 公开告知黑客“归还资金是安全的”，而黑客自称是“好人”，使得这一事件的意图和解决方式更加复杂。

    黑客向 Liquid Network 归还 2.7 亿美元比特币，此前盗走 3.2 亿美元

    攻击 Liquid Network 的黑客在最初盗走约 3.2 亿美元比特币后，归还了约 2.7 亿美元。此次部分归还意味着仍有大约 5000 万美元被盗比特币下落不明。 在加密货币盗窃案中归还大部分被盗资产并不常见，这可能会在一定程度上恢复用户对 Liquid Network（交易所用于结算的比特币侧链）的信心。尽管如此，此次漏洞仍暴露出许多交易所运作所依赖的侧链与托管基础设施的安全弱点。 Liquid Network 在遭到攻击后暂停了所有交易，黑客在归还资金时自称“好人”。关于具体的攻击手段以及剩余被盗比特币的下落，尚未得到公开证实。

    Liquid 侧链暂停：联邦钱包流出 3,998 BTC

    Blockstream 旗下 Liquid 侧链在几乎全部用于支持 L-BTC 的比特币储备（约 3,998 BTC）被提取至一个单一地址后，暂停了其桥接节点。收款方在交易中写入“我们是白帽黑客”。 此事件影响重大，因为 L-BTC 是一种 1:1 比特币锚定资产，其锚定的安全性取决于联邦钱包的储备。如果被提取的比特币无法妥善保管并归还，Liquid 及同类侧链的信任可能受到动摇。 该笔转账使联邦钱包中的比特币储备几乎归零，在资金归还前可能无法进行 peg-out（脱钩提现）。地址所有者的“我们是白帽黑客”信息暗示这是一次声明的救援行动，但尚未有官方确认发布。
