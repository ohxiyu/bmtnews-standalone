    FomoPeek iPhone App Shipped iOS Exploit Kit to Steal Crypto Wallet Keys

    Security researchers found that FomoPeek, an iPhone app marketed as a read-only whale-tracking tool for Solana, Ethereum and TRON wallets, contained malicious code capable of escaping iOS security restrictions and extracting cryptocurrency wallet credentials from affected devices. SlowMist issued an asset-theft warning about the app on September 19, and users have reported follow-on wallet drains. This shows that mobile app distribution channels can be turned into a delivery vehicle for full iOS exploit kits aimed specifically at crypto self-custody keys, shifting the attack surface from exchanges and protocols to individual users' phones. Because the kit is reusable and wrapped in an ordinary consumer app, the same technique can be resold and repackaged against other wallet-holding audiences. The malicious framework reportedly implements eight methods and performs model- and version-aware selection of exploits, so a criminal buyer can wrap prebuilt exploit packs in essentially any app shell. It sits in the same product category as previously disclosed iOS exploit kits such as the 23-exploit Coruna kit and the DarkSword Safari chain, while no confirmed aggregate loss figure has been published for FomoPeek.

    SlowMist and OKX Confirm Kernel-Level Spy Code in FomoPeek App

    Blockchain security firm SlowMist (Slow Fog) and the security team at crypto exchange OKX jointly confirmed that the FomoPeek app ships with spy code that operates at the kernel level of the user's device, according to a report carried by ababnews.com and a parallel warning published by blockchain.news. Kernel-level malware sits below the normal app sandbox, so it can reach data that ordinary app permissions cannot, making the finding a direct threat to wallet secrets and personal data of anyone who installed the app; the involvement of a major exchange's security team also signals that the threat is being treated as credible rather than speculative. Because the offending code runs with kernel privileges, it is difficult for a user to detect or remove through ordinary app uninstallation, and security researchers typically advise treating an infected device as fully compromised, up to and including reflashing or abandoning the device for any wallet-related activity.
