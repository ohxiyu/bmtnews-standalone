# UI 规则

适用于当前静态站点与分享卡片；修改先核对现有模板、CSS 和 [PWA 手册](pwa-reader.md)，不要按其他项目截图重设计。

- 保持现有信息流、事件线、实体、周报、RSS 导航和中英切换；来源管理不加入公开主导航，入口保持 /s。
- 首页默认两期；当前刊期和旧刊期必须可区分，不能把昨日排行冒充今日。
- 延续简洁紧凑排版。标题均衡换行，避免孤字；桌面正文限制阅读行宽，移动端不额外缩窄。
- 正文合理分段且完整呈现；背景、影响、来源与标签字号较小但可读，不靠两行截断隐藏主要内容。
- 移动和桌面均提供“分享”入口；面板含保存图片、复制图片及 X 分享。不得宣称 X intent 能自动附上本地图片。
- 分享图沿用手机阅读样式，保留内容/来源/分析，排除交互按钮和浏览器浮层；不显示 localhost 链接。
- 响应式、暗色、中英长标题、空状态、加载失败、键盘/焦点均需按变更范围验收。UI PR 附变更前后图片和视口尺寸，功能测试不能代替视觉验收。
- 不凭空统一所有组件，尽量复用既有样式与渲染器；不改动与任务无关的菜单。
