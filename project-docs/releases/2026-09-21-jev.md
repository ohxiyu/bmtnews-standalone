## 行为与范围

Jev 正式承担初筛、影响力/信息增量评分、分类、候选新闻对去重，以及双语扩写
和翻译的来源一致性核验。DeepSeek 保留摘要、标签、扩写和事件叙述。
新模型不会覆盖已有时效零分拒绝，也不会阻塞 Quick Post 手工插入。
低概率去重保留新闻；模型异常有有界重试和原有严格去重回退。
核验失败的生成内容不得借翻译回退绕过检查。维持现有来源、调度、配额、
Asia/Shanghai 窗口及通知/分发历史。

新增 Evaluation HTTP 客户端，不增加依赖。缓存按配置、规则、时间输入隔离。
Actions Secret AI_GATEWAY_API_KEY 已通过 GitHub 页面保存确认；文档和代码均无密钥。
