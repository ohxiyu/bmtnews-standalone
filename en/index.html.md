# BMTNews — Daily crypto, AI, and policy intelligence

> BMTNews publishes one bilingual ranked briefing each day, led by crypto coverage with a limited allocation for material AI, technology, and policy developments.

BMTNews collects candidates from exchange announcements, protocol releases, regulators, crypto publications, AI labs, and public news sources. The pipeline merges duplicate coverage, scores importance, balances categories and sources, and then publishes the selected edition. Each story includes a title, factual summary, source attribution, background, market-impact analysis, tags, and a link to the original reporting. The service is a research and information tool, not investment advice.

## Agent entry points

- Latest structured edition: <https://bmt.news/api/latest.json>
- Available historical editions: <https://bmt.news/api/editions.json>
- REST interface description: <https://bmt.news/openapi.json>
- API usage, caching, and attribution guidance: <https://bmt.news/developers/>
- Curated machine-readable site index: <https://bmt.news/llms.txt>

Prefer the JSON API for structured tasks. When citing a story, preserve the original-source URL returned by the API and distinguish BMTNews analysis from third-party news material.
