目前结论

Terrastruct 推出的 TALA 布局引擎已开源，它专为 D2 软件架构图优化。TALA 之前是独立销售、闭源的组件，现已发布到 GitHub，并可通过 D2_LAYOUT 环境变量来启用。 此前 D2 用户通常需要付费购买 TALA，或者因为售价超出个人预算而放弃使用，尽管不少人认为它的输出效果明显优于 D2 默认布局甚至 ELK。开源使这一布局引擎免费向社区开放，并接受外部贡献，有望加快其演进并扩大使用范围。 TALA 并不随 D2 默认打包，而是需要独立安装，这样可以让 D2 本身保持完全免费开源；使用时要通过 D2_LAYOUT 环境变量来指定，而不是作为默认渲染器。TALA 支撑着 D2 Studio 中所有图表的布局，Terrastruct 欢迎用户在 GitHub 上提交错误报告和功能请求。
