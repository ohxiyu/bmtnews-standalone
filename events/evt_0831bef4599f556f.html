目前结论

World 已将客户端零知识身份证明工具包 ProveKit 开源，该工具使用 Rust 编写并提供 WebAssembly 绑定。ProveKit 自 4 月起就已投入 World ID 的生产环境使用。 此举让身份与隐私开发者能够获得经过生产验证的工具包，直接在用户设备上生成和验证零知识证明，无需可信设置或服务器往返。这降低了在 Web 与 Web3 应用中构建私密“人类身份证明”系统的门槛。 该工具包将 prover、verifier 和电路编译器集成到一个轻量级组件中，可把 Noir 电路转换为可验证的 WHIR 证明。开发者可以在本地、Rust 服务、浏览器、iOS/Android，或通过 Groth16 递归验证器在链上完成证明验证。
