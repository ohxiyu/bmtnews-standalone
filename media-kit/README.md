## 颜色与留白

- 主站蓝：#1D4C96；暖白背景：#FAF9F7；正文墨黑：#1B1B18。
- 深色模式标志：#8FB0E6；字标：#E8E6E1；建议背景：#111214。
- 标志四周至少保留其高度的 1/8；不要拉伸、旋转或额外加渐变、描边和阴影。
- 推荐独立标志显示高度不低于 24 px；更小场景使用专门的 favicon 文件。
- maskable 版本留有安全裁切空间，不要放大其中的图案填满图标。

## 更新说明

网站内嵌标志随页面和主题更新。已安装的 PWA 可先在「阅读 → 检查更新」中
启用新版；操作系统桌面图标的刷新时机由浏览器与系统决定，不保证立即变化。
不需要清除阅读记录。不要为了图标更新而贸然卸载，卸载可能丢失本机数据。
